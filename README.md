# Luminosa Café

Application web développée pour **Luminosa – With Love, Rachel**, une cafétéria située à Bordeaux.

Le projet a pour objectif de présenter l'établissement, sa carte et ses événements, tout en proposant une interface d'administration permettant à la propriétaire de gérer les contenus du site.

## Stack technique

- Front-End : React, Vite, React Router, Bootstrap, Sass
- Back-End : Symfony
- Base de données : MySQL
- ORM : Doctrine
- Versionnement : Git / GitHub

## État du projet

La phase de conception est terminée et le développement du Front-End a commencé.

L'application React a été initialisée avec Vite en JavaScript. L'environnement Front-End est installé et la première exécution locale de l'application a été vérifiée avec succès.
